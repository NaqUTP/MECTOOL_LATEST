# MEC TOOL Web App

This Streamlit app allows users to interact with the MEC TOOL Excel file to:
- Input project details
- Select personnel, category, and unit rate type
- View dynamic calculations of hours and cost
- Display a summary page
- Download the summary as an Excel file

## How to Run

1. Place `MEC TOOL.xlsx` in the same folder.
2. Install requirements:
   pip install -r requirements.txt
3. Run the app:
   streamlit run app.py
